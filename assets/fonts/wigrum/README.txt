Wigrum is a commercial typeface by Production Type / Feedtype.

To use licensed webfont files in this project, place them here as:
- Wigrum-Regular.woff2
- Wigrum-Medium.woff2

Version 26 already includes local-font detection. If Wigrum is installed on the
viewer’s computer, the local font is used automatically. Otherwise the page uses
Helvetica Neue / Helvetica / Arial until licensed webfont files are supplied.
